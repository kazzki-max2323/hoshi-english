# 星降るイングリッシュ

星降る浜辺で、ゲーム感覚で英単語をおぼえるアプリです（こども向け・おとな向け）。
背景の浜辺と音は「星降るポーカー」からそのまま持ってきています。

## あそびかた

- **コース**：こども（絵文字つきのやさしい単語）／おとな（日常・ビジネスでよく使う単語）
- **モード**
  - いみを えらぶ：英語を見て、意味をえらぶ
  - えいごを えらぶ：日本語を見て、英語をえらぶ
  - ききとり：発音を聞いて、意味をえらぶ
  - にがてを ふくしゅう：まちがえた単語だけを出題する
- 1回10問です。正解するとコインがもらえ、連続正解でボーナスが増えます。全問正解すると浜辺に何かがやってきます。
- コインで「浜辺の かざり」を買うと、浜辺に飾られます。
- 浜辺の時間は現実の3時間で1日進み、夜明け・昼・夕暮れ・夜と移り変わります。

## ファイル構成

| パス | 内容 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `beach/scene.js` | 浜辺の描画と音（星降るポーカーから切り出したもの。中身は変えていません） |
| `beach/scene.css` | 浜辺まわりのスタイル（同上） |
| `beach/host.js` | 浜辺が参照するゲームの状態（コイン、音のON/OFF、時刻、飾り）と保存 |
| `beach/host-after.js` | ゲーム内時計と、ゲームから浜辺を操作する `BEACH` |
| `game/words.js` | 単語リスト |
| `game/game.js` / `game/game.css` | クイズ、結果、お店の画面 |
| `sw.js` / `manifest.webmanifest` | ホーム画面に追加できるアプリ（PWA）にするためのファイル |

## 公開のしかた

静的ファイルだけで動きます。GitHub Pages や https://app.netlify.com/drop にフォルダごと置けば公開できます。

ゲームを更新したら、`sw.js` の `CACHE` の名前（`hoshienglish-v1`）を `v2` などに変えてください。みんなの端末に新しい版が届きます。

## ローカルで動かす

```sh
python3 -m http.server 8000
# → http://localhost:8000 を開く
```
