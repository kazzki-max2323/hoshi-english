# 星降るイングリッシュ

星降る浜辺で、ゲーム感覚で英単語をおぼえるアプリです（こども向け・おとな向け）。
背景の浜辺と音は「星降るポーカー」からそのまま持ってきています。

## あそびかた

- **単語帳**：ホームの「小学生／中学生／高校生／ハイレベル」を押すと、1冊20語の単語帳が並んだ本棚が開きます。カードは表が英語、裏が日本語。タップでめくり、左右のスワイプで次と前へ。🔊で発音を聞けます。
  - 小学生：小学校で習う量にあわせて31冊・620語（絵文字つき）
  - 中学生・高校生・ハイレベル：各15冊・300語
- **ラジオ**：ショップでレベル別のラジオを手に入れると浜辺に置かれます（小学生ラジオは無料）。オンのラジオからランダムに英単語や短い文が流れ、日本語訳の吹き出しが浜辺に浮かびます。正しい吹き出しをタップするとコインがもらえます（小学生ラジオは1枚、流れてから5秒以内なら2枚）。浜辺のラジオをタップするとオン・オフ、間隔はバーで3〜30秒（最初は10秒）。単語帳やショップを開いている間は止まります。
- **ショップ**：ラジオの売り買いと、浜辺のかざり。
- **ミニゲーム**：準備中。
- 浜辺の時間は現実の3時間で1日進み、夜明け・昼・夕暮れ・夜と移り変わります。

## ファイル構成

| パス | 内容 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `beach/scene.js` | 浜辺の描画と音（星降るポーカーから切り出したもの。中身は変えていません） |
| `beach/scene.css` | 浜辺まわりのスタイル（同上） |
| `beach/host.js` | 浜辺が参照するゲームの状態（コイン、音のON/OFF、時刻、飾り）と保存 |
| `beach/host-after.js` | ゲーム内時計と、ゲームから浜辺を操作する `BEACH` |
| `game/levels/*.js` | レベルごとの単語帳とラジオのセリフ |
| `audio/<レベル>.mp3` / `.json` | 単語とセリフの発音（レベルごとに1つの音声にまとめ、`.json` に各単語の開始位置と長さ） |
| `game/game.js` / `game/game.css` | ホーム、単語帳、ラジオ、ショップの画面 |
| `sw.js` / `manifest.webmanifest` | ホーム画面に追加できるアプリ（PWA）にするためのファイル |

## 発音の音声について

発音は Kokoro（Apache-2.0 の読み上げモデル、`kokoro-onnx`）で作った録音です。単語やセリフを増やしたときは、同じ方法で `audio/` を作り直してください。録音にない言葉は、ブラウザの読み上げ機能で代わりに読みます。

## 公開のしかた

静的ファイルだけで動きます。GitHub Pages や https://app.netlify.com/drop にフォルダごと置けば公開できます。

ゲームを更新したら、`sw.js` の `CACHE` の名前（`hoshienglish-v1`）を `v2` などに変えてください。みんなの端末に新しい版が届きます。

## ローカルで動かす

```sh
python3 -m http.server 8000
# → http://localhost:8000 を開く
```
