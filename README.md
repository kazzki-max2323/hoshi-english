# 浜辺の英語

星降る浜辺で、ゲーム感覚で英単語をおぼえるアプリです（こども向け・おとな向け）。
背景の浜辺と音は「星降るポーカー」からそのまま持ってきています。

## あそびかた

- **単語帳**：ホームの「小学生／中学生／高校生／ハイレベル」を押すと、1冊20語の単語帳が並んだ本棚が開きます。カードは表が英語、裏が日本語。タップでめくり、左右のスワイプで次と前へ。カードが出ると英語を自動で読みあげ、🔊でもう一度聞けます（自動の読みあげは設定でオフにできる）。上にスワイプ（または✓）で「おぼえた」にでき、「のこりだけ」で覚えていないカードだけをめくれます。
  - 小学生：小学校で習う量にあわせて31冊・620語（絵文字つき）
  - 中学生：教科書の量にあわせて79冊・1,580語（不規則動詞は「begin, began, begun」の形でまとめて覚える）
  - 高校生：教科書と英検2級の量にあわせて106冊・2,120語
  - ハイレベル：英検準1級〜1級・TOEIC 800点以上の語で115冊・2,300語（ビジネス、TOEIC頻出、学問分野別、語源で覚える など）
- **おうえんメッセージ**：遊んでいると5分に1回くらい、空に「この努力は 必ず チカラになる」のような ひとことや、偉人・キャラクターの言葉（英語つき）がうかぶ。英語の言葉はタップで発音が聞ける。ラジオや住人とは順番こ：ラジオや住人が話し終わるのを待ってから出て、出ているあいだはラジオも住人も静かにし、消えて10秒たつとラジオが再開する。設定でオフにできる。中身は `game/extras/cheer.js`
- **🃏 カード図鑑**：コインで「宝箱くじ」を引いて、1000種類のカード（英語の名前つき・タップで発音）を集める。1回80枚、10回720枚（SR以上1枚かくてい）、1日1回むりょう。レア度は N 60%・R 27%・SR 9.5%・SSR 3%・UR 0.5%。ダブったカードは「星のかけら」になり（N1・R3・SR10・SSR40・UR150）、かけらで まだ持っていないカードと交換できる（N15・R45・SR150・SSR500・UR1500）。ダブったら、つぎの同じレア度は かならず新しいカード。18のシリーズ（海の生きもの、乗りもの、世界の国と地域 など）をそろえるとコンプリートのお祝い。データは `game/cards-data.js`、画面は `game/cards.js` / `game/cards.css`
- **画面のとじ方**：単語帳・ショップ・設定・文法ノート・宝の地図などは、枠の外（浜辺）をタップすると「←」と同じように1つ前にもどる。ミニゲームの最中と宝箱の画面は、外をタップしても閉じない。
- **ラジオ**：ショップでレベル別のラジオを手に入れると浜辺に置かれます（小学生ラジオは無料。同じラジオは1台まで）。オンのラジオからランダムに英単語や短い文が流れ、日本語訳の吹き出しが浜辺に浮かびます。正しい吹き出しをタップするとコインがもらえます（小学生ラジオは1枚、流れてから5秒以内なら2枚）。浜辺のラジオをタップするとオン・オフ、間隔はバーで3〜30秒（最初は10秒）。単語帳やショップを開いている間は止まります。出る割合は 単語45%・キャラや流行りの英文15%・文40%（文はレベルごとに約170〜190こ、星空ラジオは42こ。季節の行事の期間は季節の文もまざる）。
- **ショップ**
  - 📻 ラジオ：レベル別のラジオの売り買い
  - 🏖️ かざり：浜辺に置く37種類。売ると半額もどる
  - 🎵 おんがく：32曲。一度買えばいつでも流せる。売ると半額
  - 🎆 イベント：花火やオーロラ、イルカ、UFOなど。1回ずつ使いきりで、時間帯が決まっているものもある
- **📚 文法ノート**：小学生14冊・中学生28冊・高校生20冊。教科書の文法（複数形、三単現、過去形、進行形、未来、助動詞、比較、受け身、現在完了、不定詞・動名詞、関係詞、分詞、仮定法、話法、倒置など）をひととおり。1冊にルール・発音つきの例文3つ・れんしゅう3問。ショップの「📚 文法」で1冊ずつ（小30・中60・高100枚）か、学年ごとにまとめて2割引きで買える。ホームの「📚 文法」から読み、れんしゅうを全問正解するとクリア（最初の1回だけコイン）。
- **季節のイベント**：月ごとに「季節の単語帳」（お正月・バレンタイン・春・梅雨・夏・秋・ハロウィン・クリスマス）が本棚の一番上に出て、ラジオでも季節のセリフが流れる。
- **キャラクター・流行りの英文**：コナン、ポケモン、マリオ、ジブリ、ラブブなどの名前を使ったオリジナルの英文が、レベルごとの難しさでラジオに混ざって流れる。
- **🌙 星空ラジオ**：ショップで買える、夜だけ宇宙と星の英語をしゃべるラジオ（昼は💤）。
- **浜辺の住人**：浜辺の飾りが増えるほど住人が増える（ネコのミケ、カニ吉、ペンタ、ラッコ、じいガメ、夜だけのフクロウ博士）。10分に1回くらい歩いてきて、タップすると英語で話しかけてくる。日本語訳を当てるとコイン。
- **⚙️ 設定**：効果音・波の音・BGM・英語の発音の音量と、発音の速さ（ふつう／ゆっくり）。
- **🗺️ 宝の地図**：分かれ道のある地図を、ミニゲームをクリアしながらゴールの宝箱まで進む冒険。3枚の地図（さざなみ海岸・ほたる入り江・星くず岬）があり、宝箱からはショップでは手に入らないレアなもの（飾り・曲・いつでも呼べるイベント・称号）が出る。
  - ミニゲーム：🐚 貝がらつり（意味）／📻 DJチャレンジ（聞き取り・語順）／✨ 星座つなぎ（スペル）／🍉 スイカ割り（英語の指示を聞いて動く）／🦀 カニの早押し（聞き取り）。問題は地図で選んだレベルから出る
  - 挑戦にコインが必要（クリアで2倍もどる）。失敗すると1マス もどる
  - 🏪 冒険のお店で道具が買える：🧭 コンパス（失敗しても もどらない）／⏳ 砂時計（+10秒）／💡 ヒント貝。❓ ひみつのマスでは コインや道具が見つかる
- 浜辺の時間は現実の3時間で1日進み、夜明け・昼・夕暮れ・夜と移り変わります。

## ファイル構成

| パス | 内容 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `beach/scene.js` | 浜辺の描画と音（星降るポーカーから切り出したもの。中身は変えていません） |
| `beach/scene.css` | 浜辺まわりのスタイル（同上） |
| `beach/host.js` | 浜辺が参照するゲームの状態（コイン、音のON/OFF、時刻、飾り）と保存 |
| `beach/host-after.js` | ゲーム内時計と、ゲームから浜辺を操作する `BEACH` |
| `game/levels/*.js` | レベルごとの単語帳とラジオのセリフ。`jh-more.js` / `hs-more.js` / `adv-more.js` は `tools/wordsrc/` の元データから `tools/merge_books.js` で作った追加分（同じレベルで重なる単語を除いて1冊20語。足りない冊は `*_FILL` の品詞別の語でうめる） |
| `audio/<レベル>.mp3` / `.json` | 単語とセリフの発音（レベルごとに1つの音声にまとめ、`.json` に各単語の開始位置と長さ）。`audio/suika.*` はスイカ割りの指示の声 |
| `game/extras/pop.js` / `season.js` / `folk.js` | キャラクター・流行りの英文、季節の単語帳とセリフ、星空ラジオと浜辺の住人 |
| `game/grammar/es.js` / `jh.js` / `hs.js` | 文法ノート（ルール・例文・れんしゅう問題） |
| `game/catalog.js` | ショップの品物（かざり・おんがく・イベント）と値段 |
| `game/adventure.js` / `game/adventure.css` | 宝の地図とミニゲーム |
| `game/game.js` / `game/game.css` | ホーム、単語帳、ラジオ、ショップの画面 |
| `sw.js` / `manifest.webmanifest` | ホーム画面に追加できるアプリ（PWA）にするためのファイル |

## 発音の音声について

発音は Kokoro（Apache-2.0 の読み上げモデル、`kokoro-onnx`）で作った録音です。単語やセリフを増やしたときは、同じ方法で `audio/` を作り直してください。録音にない言葉は、ブラウザの読み上げ機能で代わりに読みます。

## 公開のしかた

静的ファイルだけで動きます。GitHub Pages や https://app.netlify.com/drop にフォルダごと置けば公開できます。

アプリ名は「浜辺の英語」（もとは「星降るイングリッシュ」）。保存データの名前（`hoshienglish`）や URL（`hoshi-english`）は、今までの進み具合を消さないように そのままにしている。

ゲームを更新したら、`sw.js` の `CACHE` の名前（`hoshienglish-v22` など）の数字を1つ上げてください。端末はいつもネットの最新版を先に読みこみ（つながらないときだけ保存した版を使う）、新しい版に入れかわるとホーム画面にいるときに1回だけ自動で読みこみ直します。音声は聞いたときに保存され、版を上げても消えません。
